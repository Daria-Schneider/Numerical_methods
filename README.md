# Численные методы

Лабораторные работы по дисциплине «Численные методы», МАИ. Вариант 27.

Все работы написаны на C++17, сборка через CMake.

## Лабораторные работы

1. [Методы решения задач линейной алгебры](./Lab1/README.md)
2. Методы решения нелинейных уравнений и систем нелинейных уравнений
3. Методы приближения функций. Численное дифференцирование и интегрирование
4. Методы решения начальных и краевых задач для ОДУ и систем ОДУ

## Структура репозитория

- `CMakeLists.txt` - общий файл сборки
- `data/lab1/` - входные данные для лабораторной 1
- `Lab1/` - лабораторная 1:
  - `main.cpp` - меню выбора задания
  - `include/` - заголовочные файлы
  - `src/` - реализация методов (по одному файлу на задание)

## Сборка и запуск

Нужны компилятор g++ с поддержкой C++17, CMake и Ninja.

Команды выполняются из корня репозитория:

```
cmake -S . -B build -G Ninja -DCMAKE_CXX_COMPILER=g++
cmake --build build
./build/bin/lab1.exe
```

После запуска появляется меню, в нем вводится номер задания. Номер можно передать
сразу при запуске: `./build/bin/lab1.exe 3`.

Входные данные читаются из файлов в папке `data`, поэтому если поменять в них числа,
пересобирать программу не нужно.
