# Численные методы

Лабораторные работы по дисциплине «Численные методы», МАИ. Вариант 27.

Все работы написаны на C++17, сборка через CMake.

## Лабораторные работы

1. [Методы решения задач линейной алгебры](./Lab1/README.md)
2. [Методы решения нелинейных уравнений и систем нелинейных уравнений](./Lab2/README.md)
3. [Методы приближения функций. Численное дифференцирование и интегрирование](./Lab3/README.md)
4. [Методы решения начальных и краевых задач для ОДУ и систем ОДУ](./Lab4/README.md)

## Структура репозитория

- `CMakeLists.txt` - общий файл сборки
- `data/lab1/` ... `data/lab4/` - входные данные для лабораторных 1-4
- `Lab1/` - лабораторная 1:
  - `main.cpp` - меню выбора задания
  - `include/` - заголовочные файлы
  - `src/` - реализация методов (по одному файлу на задание)
- `Lab2/` - лабораторная 2, устроена так же, плюс:
  - `plots.py` - графики для выбора начального приближения
  - `images/` - сами графики
- `Lab3/` - лабораторная 3, устроена так же, `plots.py` строит график к заданию 3.3
- `Lab4/` - лабораторная 4, устроена так же, как лабораторная 1

## Сборка и запуск

Нужны компилятор g++ с поддержкой C++17, CMake и Ninja.

Команды выполняются из корня репозитория:

```
cmake -S . -B build -G Ninja -DCMAKE_CXX_COMPILER=g++
cmake --build build
./build/bin/lab1.exe
./build/bin/lab2.exe
./build/bin/lab3.exe
./build/bin/lab4.exe
```

После запуска появляется меню, в нем вводится номер задания. Номер можно передать
сразу при запуске: `./build/bin/lab1.exe 3`.

Входные данные читаются из файлов в папке `data`, поэтому если поменять в них числа,
пересобирать программу не нужно.
