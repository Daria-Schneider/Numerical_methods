## Задание 4.1. Задача Коши

### Условие
Реализовать методы Эйлера, Рунге-Кутты и Адамса 4-го порядка в виде программ, задавая в качестве входных
данных шаг сетки h. С использованием разработанного программного обеспечения решить задачу Коши для ОДУ
2-го порядка на указанном отрезке. Оценить погрешность численного решения с использованием метода
Рунге-Ромберга и путем сравнения с точным решением.

### Вариант 27
$$
x^2y'' - 2xy' + (x^2 + 2)y = 0, \quad y(\pi/2) = \pi/2, \quad y'(\pi/2) = 1 - \pi/2, \quad
x \in [\pi/2, \pi/2 + 1], \quad h = 0.1
$$
Точное решение: $y = x\cos x + x\sin x$.

### Решение
Заменой $z = y'$ уравнение сводится к системе первого порядка:
$y' = z$, $z' = (2xz - (x^2 + 2)y) / x^2$.

- метод Эйлера (4.2), порядок 1;
- метод Рунге-Кутты 4-го порядка для системы (4.16);
- метод Адамса 4-го порядка (4.25), первые три узла считаются методом Рунге-Кутты.

Для оценки Рунге-Ромберга (4.11) задача решается еще раз с шагом 2h:
$R = \frac{y_h - y_{2h}}{2^p - 1}$, где p - порядок метода.

### Входные данные
`input_4_1.txt`: шаг h. Уравнение и начальные условия записаны в коде.
```
0.1
```

## Задание 4.2. Краевая задача

### Условие
Реализовать метод стрельбы и конечно-разностный метод решения краевой задачи для ОДУ в виде программ.
С использованием разработанного программного обеспечения решить краевую задачу для обыкновенного
дифференциального уравнения 2-го порядка на указанном отрезке. Оценить погрешность численного решения
с использованием метода Рунге-Ромберга и путем сравнения с точным решением.

### Вариант 27
$$
(2x + 1)y'' + (2x - 1)y' - 2y = x^2 + x, \quad y'(0) = 1, \quad y'(1) + y(1) = 5
$$
Точное решение: $y = 2x - 1 + e^{-x} + \frac{x^2 + 1}{2}$.

Шаг в варианте не задан, взят h = 0.1. Точность и начальные значения для стрельбы взяты как в примере 4.9.

### Решение
**Метод стрельбы.** Неизвестное значение $y(0)$ обозначается $\eta$. Задача Коши с $y(0) = \eta$,
$y'(0) = 1$ решается методом Рунге-Кутты, а $\eta$ подбирается методом секущих (4.34) так, чтобы
$\Phi(\eta) = y'(1) + y(1) - 5 = 0$.

**Конечно-разностный метод.** Уравнение делится на $2x + 1$:
$y'' + p(x)y' + q(x)y = f(x)$. Во внутренних узлах производные заменяются центральными разностями (4.37),
на концах односторонними разностями 2-го порядка (4.41). Лишнее неизвестное в первой и последней строке
исключается через соседнее уравнение, поэтому матрица остается трехдиагональной и решается прогонкой.

Оценка Рунге-Ромберга такая же, как в 4.1: p = 4 у стрельбы и p = 2 у разностного метода.

### Входные данные

```

```

уравнение линейное и $\Phi(\eta)$ - прямая.
